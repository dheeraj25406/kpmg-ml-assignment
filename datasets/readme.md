Performed EDA.

For Code quality prediction, the dataset chosen is Software Detect Dataset by NASA, taken from kaggle. 
Dataset link : https://www.kaggle.com/datasets/radowanulhaque/software-defect

Other options available are CodeXGLUE defect, not chosen as the dataset is mostly in C++.
Tools like redon and pythonast work only for python.
For c++, we need clang, lizard and other requirements, increasing complexity.

IBM Codenet dataset is also a standard dataset, not chosen as it is very huge,
approximately of 7.8 GB, needs more computational power.


For Doubt solving triage, stack overflow struck in my mind after hearing the problem statement : )

Selected dataset is 60k Stack Overflow Questions with Quality Rating dataset, taken from Kaggle.
Dataset link : https://www.kaggle.com/datasets/imoore/60k-stack-overflow-questions-with-quality-rate

Searched other good stack overflow datasets, complete dataset was available in Kaggle but needed to 
be downloaded from Bigquery as it was too large, needs a lot of computational power.

Also, it was the same case with EdNet dataset.
